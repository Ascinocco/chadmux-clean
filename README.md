# Chadmux

A native SwiftUI client for tmux sessions over SSH, on iPhone and macOS. It's
built for running Claude Code on your own machines (This Mac, a home server)
from anywhere on your tailnet. The iPhone has a composer with photos and
dictation; the Mac is a cmux-style terminal window where you drop images
straight onto Claude.

- [PROJECT.md](PROJECT.md): architecture, behaviour and build commands.
- [docs/runbooks/](docs/runbooks/README.md): how to run, install, test, validate
  and troubleshoot Chadmux on the iPhone and the Mac.
