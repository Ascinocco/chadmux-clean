# Agent entry point

Read `PROJECT.md` for this repository's purpose, architecture, commands and
operational boundaries. It is the shared technical source for all agents.
Read any applicable repository-local instructions referenced there in full.

Before editing, verify the assigned repository, worktree and branch. Surface
missing instructions and material conflicts with the task brief before taking
a dependent action. Preserve unrelated work.

When a coordinator supplies shared factory procedures, read the explicitly
provided files as well. A standalone checkout does not require access to a
factory installation; coordination context belongs in the task handoff.
